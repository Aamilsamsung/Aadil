# Cloudflare deployment

This is a Next.js application, not Vite. Deploy with **Cloudflare Workers** using OpenNext.

1. Install dependencies with `pnpm install` (Node.js 20+).
2. Build with `pnpm run preview:cloudflare` to test locally.
3. In Cloudflare Workers & Pages, import this GitHub repository.
4. Build command: `npx opennextjs-cloudflare build`.
5. Deploy command: `npx opennextjs-cloudflare deploy`.
6. Configure the Cloudflare account and any optional secrets in Cloudflare.
